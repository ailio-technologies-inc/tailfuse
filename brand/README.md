# Brand

The fused-dots mark: two dot grids joined by a bar, two networks fused. Bone `#eff0f1`,
safety orange `#ff4a1f`, on graphite `#18191b`. Type: Host Grotesk and JetBrains Mono.

| File | Used for |
|---|---|
| `app-icon.svg` | The app icon (rounded tile with margin); source of every size in `app/src-tauri/icons` |
| `app-icon-square.svg` | Full-bleed tile: touch icons, other sites' product lists |
| `favicon.svg` | The site's favicon (bigger dots for 16–32 px) |
| `mark.svg` | The mark without a tile: window and site headers |
| `tray.svg` | The menu-bar glyph (grey and orange, readable on light and dark bars) |

After changing any of them, run `scripts/gen-icons.sh`.
