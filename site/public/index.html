Tailfuse is a menu-bar app for macOS, Windows and Linux. It runs one Tailscale node per tailnet and sends each hostname to the tailnet that owns it.

Browsers read the PAC file, send owned hostnames to the router and connect direct for the rest.

Isolation between tailnets

Two full Tailscale daemons fight over routes, DNS and firewall rules. Tailfuse runs each tailnet in userspace networking mode, so the kernel routing table stays as it was.

Leaves your Tailscale client alone

Each tailnet runs without a TUN device, a route or a DNS change. The official client keeps its primary tailnet.

tailscaled --tun=userspace-networking

Refuses hostnames nobody owns

Each suffix belongs to one profile and overlaps fail validation. An unowned name is refused, never sent to another tailnet.

suffixes: [.work.ts.net, .internal.example]

Runs as your user

Tailfuse installs neither a root helper nor a kernel extension. The one system setting it changes is your Mac’s automatic proxy address, set once with your permission and removable from the app’s settings.

http://127.0.0.1:43100/tailfuse.pac

Pins a local port to a tailnet service

A tunnel maps a port on this machine to one service on one tailnet, so a database client connects with no proxy settings.

127.0.0.1:5432profile workdb.work.ts.net:5432

Keys locked to your account

Each tailnet keeps its node keys and its control socket in a folder only your account can open, so another user on the same computer can neither read them nor drive the connection. Auth keys and your license key live in the macOS Keychain or Windows Credential Manager, never in a config file, and nothing is sent to us.

~/Library/Application Support/tailfuse drwx------ license Keychain

The same router in a terminal

The tailfuse command shares its core with the menu-bar app. Both read one config file.

~/.config/tailfuse/config.yaml
profiles:
  personal:
    suffixes: [.home-lab.ts.net]
  work:
    suffixes: [.work.ts.net, .internal.example]
    accept_routes: true
    exit_node: exit-us
tunnels:
  - name: prod-db
    profile: work
    listen: 127.0.0.1:5432
    target: db.work.ts.net:5432
tailfuse profile login workSigns a profile in through the browser, once per tailnet.
tailfuse upStarts everything and sets the system PAC.
tailfuse statusShows each profile's state, hostname and Tailscale IPs.
tailfuse ssh user@host.work.ts.netOpens SSH through the profile that owns the host.
tailfuse run curl http://wiki.work.ts.netRuns any command with the proxy environment set.
tailfuse envPrints the proxy environment for your shell.
tailfuse downClears the system PAC.

What does a license cost?

Whatever you choose, including nothing. The donation is optional, and a $0 key is the same key as a $10 one.

Is Tailfuse made by Tailscale?

No. Tailfuse is an independent tool. It runs the tailscaled binary, which stays under the Tailscale terms.

Does it replace the Tailscale app?

No. An installed Tailscale client keeps owning the primary tailnet, and Tailfuse adds the others beside it.

Can a server log in unattended?

Yes. Put a Tailscale auth key in that profile's config and it signs in with no browser step.
