Every tailnet, behind one address on your computer

Tailfuse listens here. Your apps send tailnet traffic to this address, and Tailfuse passes each request to the tailnet that owns the hostname.

127.0.0.1:43100

Browsers

Nothing to set up. Your system’s automatic proxy setting sends tailnet addresses here, and every other site loads as usual.

The terminal

tailfuse run starts any command through it, so curl, git and scripts reach tailnet names. tailfuse ssh does the same for SSH.

Any other app

Give an app that takes a proxy this address, as SOCKS5 or HTTP. For one that can’t, Tailfuse can open a local port that leads to a single service.

Isolation between tailnets

Two full Tailscale daemons fight over routes, DNS and firewall rules. Tailfuse runs each tailnet in userspace networking mode, so the kernel routing table stays as it was.

Leaves your Tailscale client alone

Each tailnet runs without a TUN device, a route or a DNS change. The official client keeps its primary tailnet.

tailscaled --tun=userspace-networking

Refuses hostnames nobody owns

Each suffix belongs to one profile and overlaps fail validation. An unowned name is refused, never sent to another tailnet.

suffixes: [.work.ts.net, .internal.example]

Runs as your user

Tailfuse installs neither a root helper nor a kernel extension. The one system setting it changes is your Mac’s automatic proxy address, set once with your permission and removable from the app’s settings.

http://127.0.0.1:43100/tailfuse.pac

Pins a local port to a tailnet service

A tunnel maps a port on this machine to one service on one tailnet, so a database client connects with no proxy settings.

127.0.0.1:5432profile workdb.work.ts.net:5432

Keys locked to your account

Each tailnet keeps its node keys and its control socket in a folder only your account can open, so another user on the same computer can neither read them nor drive the connection. Auth keys and your license key live in the macOS Keychain or Windows Credential Manager, never in a config file, and nothing is sent to us.

~/Library/Application Support/tailfuse drwx------ license Keychain

The same router in a terminal

The tailfuse command shares its core with the menu-bar app. Both read one config file.

~/.config/tailfuse/config.yaml
profiles:
  personal:
    suffixes: [.home-lab.ts.net]
  work:
    suffixes: [.work.ts.net, .internal.example]
    accept_routes: true
    exit_node: exit-us
tunnels:
  - name: prod-db
    profile: work
    listen: 127.0.0.1:5432
    target: db.work.ts.net:5432
tailfuse profile login workSigns a profile in through the browser, once per tailnet.
tailfuse upStarts everything and sets the system PAC.
tailfuse statusShows each profile's state, hostname and Tailscale IPs.
tailfuse ssh user@host.work.ts.netOpens SSH through the profile that owns the host.

tailfuse envPrints the proxy environment for your shell.

The six tools

tailfuse_statusEach tailnet: connected or not, the account it signed in with, the suffixes it owns, and this computer's name and IPs on it.
tailfuse_list_devicesDevices on one tailnet or all of them: name, DNS name, IPs, OS and whether each is online.
tailfuse_which_tailnetWhich tailnet a hostname or URL goes to, or that no tailnet owns it.
tailfuse_http_requestAn HTTP or HTTPS request to a tailnet service. It returns the status, headers and up to 64 KB of the body.
tailfuse_check_portWhether a TCP port on a tailnet host accepts connections, such as a database on port 5432.
tailfuse_set_connectedConnects or disconnects one tailnet while Tailfuse is running.

What does a Tailfuse license cost?

Two tailnets are free. A license key for more costs whatever you choose, including nothing, and a $0 key is the same key as a $10 one.

Is Tailfuse made by Tailscale?

No. Tailfuse is an independent tool. It runs the tailscaled binary, which stays under the Tailscale terms.

Does Tailfuse replace the Tailscale app?

It can. The desktop app includes its own Tailscale runtime, so the Tailscale app is optional. An installed client can keep owning the primary tailnet while Tailfuse adds the others beside it.

Can a server log in to a tailnet unattended?

Yes. Put a Tailscale auth key in that profile's config and it signs in with no browser step. On macOS and Windows, Tailfuse then moves the key into the Keychain or Credential Manager.

Questions about Tailfuse

How it sits beside Tailscale, what it changes on your computer, and how AI assistants use it.

How do I use multiple Tailscale tailnets at once?

The Tailscale app connects to one tailnet at a time, and switching accounts disconnects the other. Tailfuse runs one Tailscale node per tailnet in userspace mode, plus a local router on 127.0.0.1:43100 that sends each hostname to the tailnet that owns it. Add a profile for each tailnet with the hostname suffixes it owns, sign each one in once, and turn Tailfuse on.

Does Tailfuse work with Claude and other MCP clients?

Yes. The tailfuse command line includes an MCP server that runs over stdio. For Claude Code, run claude mcp add tailfuse -- tailfuse mcp. Other clients take {"command": "tailfuse", "args": ["mcp"]}. In the app, Settings has the same command under AI assistants (MCP).

What can an AI assistant do through Tailfuse?

It can list your tailnets and their devices, ask which tailnet owns a hostname, make HTTP requests to tailnet services, check whether a port is open, and connect or disconnect a tailnet. Requests to a hostname no tailnet owns are refused.

Does Tailfuse change my routes or DNS?

No. Each tailnet runs without a TUN device, a route or a DNS change, and Tailfuse runs as your user with no root helper. The one system setting it changes is the automatic proxy (PAC) address, set with your permission and removable from the app's settings.

How do browsers and terminal tools reach tailnet hosts?

Browsers follow the system's automatic proxy setting. In a terminal, tailfuse run starts a command with the proxy set and tailfuse ssh opens SSH through the right tailnet. Other apps can use 127.0.0.1:43100 as a SOCKS5 or HTTP proxy, or a tunnel that pins a local port to one service.

Which systems does Tailfuse run on?

macOS (a universal app, signed and notarized), Windows on x86-64 and Linux on x86-64 as an AppImage or a .deb. The command line also comes for Linux on arm64. The desktop app bundles Tailscale's runtime; a source-built command line can use a system tailscaled. Download Tailfuse
